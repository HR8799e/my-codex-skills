# 数模图片

## 目标与范围

让图服务于模型和结论，像参赛队员根据当前题目整理出的优秀论文图。优先保证数学与数据正确、信息清楚、论文尺寸下可读，再考虑美观；根据图的用途形成合适的表达，不套用统一的装饰模板。

“降低 AI 味”指减少模板化设计，使图形选择与数学含义一致。不要故意制造错误，也不要声称能够规避 AI 检测。

本 skill 负责数模图片及生成这些图片所需的代码。完整求解程序、算法实现和通用代码风格由独立的数模代码 skill `natural-modeling-code` 负责；涉及这些任务时按需配合使用，不把两套 skill 合成一个。

## 按图的用途选择软件

先判断图要解释什么，再选择工具。用户明确指定软件或交付形式时优先遵从；未指定时按下面的偏好选择，不要求用户每次重新选软件。

| 图的用途 | 默认选择 | 表达重点 |
|---|---|---|
| 函数曲线、轨迹、模型计算形态、仿真结果、敏感性分析、真实三维曲面 | MATLAB 优先 | 坐标和曲线来自真实输入或模型计算，附可运行脚本 |
| 大规模数据、特殊统计图、网络或其他 MATLAB 不便处理的可视化 | 按实际需求选择 Python | 使用相应数据和绘图库，附可运行脚本 |
| 建模流程、算法流程、模型框架 | Visio 风格 | 层级、分支、连接关系和对齐清楚；需要代码生成时可用 Graphviz 或矢量绘图 |
| 受力分析、结构关系、二维或三维概念示意、投影关系 | Visio 优先，按几何要求选择合适工具 | 物体、方向、受力和空间关系形象具体，符号规范 |
| 强调几何构造、角度约束、交点或矢量关系 | Visio / GeoGebra；数值结果用 MATLAB / Python | 几何关系正确，构造与标注容易理解 |

不要只凭“几何图”或“三维图”选软件。比如，锚链的受力关系属于示意图；模型算出的锚链坐标形态属于结果图。三维迎流投影的概念说明与真实计算曲面也应分别判断。

简短说明这张图适合的软件、原因和将采用的风格，然后完成出图或代码交付。整篇论文的多图任务可先列出逐图选择表。

“Visio 风格”是表达偏好，不代表必须安装或已经使用 Visio。根据当前可用工具选择实现方式，并如实说明实际生成工具与文件格式。用户需要原生 Visio 文件时，不把 SVG 当作 `.vsdx`；导入后的元素可编辑性以实际验证为准。

用户给出优秀论文或参考图时，先观察其信息层级、比例和标注习惯，再结合当前内容采用合适的表达方式。蓝白配色等是用户的风格偏好，不宣称是竞赛统一规定，也不凭外观断言参考图使用了某款软件。

## MATLAB / Python 结果图

- 默认不在绘图区内放标题；给出建议图题供用户放在论文图片下方。用户明确要求图内标题时再添加。
- 保留数据、曲线或点、坐标轴、单位及必要图例，解释放到正文和图注。只有确实需要区分多组数据时才放图例。
- 不逐点标名，不堆叠长说明、箭头、文本框、渐变、阴影和装饰图标。关键节点、边界或异常点对解释有用时保留。
- 默认采用黑、灰及线型区分；黑白难以辨认时使用少量低饱和颜色。热力图等以颜色编码数值的图使用有明确含义的色标，不强制改成黑白。
- 网格默认关闭；读数确实需要时使用很淡的主网格，不添加密集次网格。
- 几何位置、轨迹和形状图保持真实坐标比例，通常使用 `axis equal` 或对应设置，除非比例调整本身是需要说明的表达决定。
- 留白以论文单栏或双栏尺寸为准，避免图例遮挡曲线、字体过小和线条过细。

## 流程图与模型框架图

- 默认白底、蓝色边框或浅蓝填充、黑色文字；蓝色用于表达层级或轻度强调，避免大面积装饰色块。
- 普通节点以方正矩形为主，判断节点用菱形；起止节点可少量使用圆角或椭圆，不采用大圆角卡片样式。
- 布局整齐，间距合理，连接线走向清楚，尽量减少交叉和绕行；分支、回路与判断条件必须表达完整。
- 节点文字简短，详细解释放正文。不能为了减少节点而删去算法的关键步骤或逻辑。
- 避免装饰图标、卡片阴影、渐变、发光和与流程无关的图形。
- 需要代码生成时，可提供 Graphviz 源码及 SVG / PDF；根据实际需求提供可编辑源文件或布局方案。

## 受力、几何与结构示意图

二维与三维按表达需要选择，没有默认优先二维的限制。需要展示空间结构、朝向、遮挡、迎流面或投影关系时，用形象具体、清楚且符合优秀论文风格的三维图表达，不为简化画面而压成难以理解的二维图。

- 物体轮廓与结构要足以识别；选择合适的视角和尺度，让关键构件、受力位置、平面和空间关系清楚。
- 保留必要名称、尺寸、坐标系、力箭头、角度弧线、虚线及数学符号，但不要把所有部件都装进文本框。
- 箭头方向、作用点、变量和角度定义与模型一致；区分可见边、隐藏边、辅助线和投影线，避免标注遮挡关键关系。
- 三维图可以使用有明确空间含义的浅色面、适度透明度或明暗区分，帮助说明曲面、遮挡与投影；不添加与数学表达无关的装饰光效、纹理或阴影。
- 默认白底，蓝、黑、灰适度区分构件或关系；按内容需要调整配色，不把结果图的黑白规则机械套用到所有示意图。
- 数值几何按真实比例绘制；概念示意可以为可读性调整布局与尺度，但不能改变几何约束。容易被当作实测或计算比例时说明是示意。

## 科学严谨性

- 结果图只画真实输入数据或模型计算结果。示例数据明确说明是示例，不能伪装成题目结果。
- 缺少真实数据时，说明缺少什么，并提供可接入数据的绘图代码；需要风格预览时将其明确标为示例。不能凭原图外观编造精确结果。
- 局部放大、截断坐标轴、归一化、平滑或筛选数据时，至少在图中、代码短注释或建议图注中说明一处。
- 误差、置信区间和约束边界对结论有影响时保留，不能为了画面干净而删除。
- 多组曲线除了颜色外，尽量同时用线型或标记区分，保证黑白打印仍能阅读。

## 绘图代码与输出

数值结果图默认交付一份可直接运行的 MATLAB 脚本；选用或明确要求 Python 时提供对应代码，不默认同时输出两套重复代码。

- 一次性绘图脚本优先从上到下写：数据或参数、必要计算、绘图、导出。只有重复计算或较长数学步骤确实需要时才定义函数。
- 变量名短而有题目含义，优先使用论文符号，如 `x`、`t`、`v`、`r`、`theta`、`err`。
- 注释只解释模型含义、特殊参数、局部放大或不明显的画图决定，不写复述操作的教程式注释。
- 不为一次性绘图添加配置类、日志、命令行参数或多层通用封装。数据文件固定时使用简单相对路径，输出放在项目中容易找到的位置。

MATLAB 默认同时保留高清位图和矢量图导出语句，文件名根据图的实际含义确定：

```matlab
exportgraphics(gcf,'result.png','Resolution',600);
exportgraphics(gcf,'result.pdf','ContentType','vector');
```

Python 绘图同时保存 600 DPI PNG 和 PDF，并设置 `bbox_inches='tight'`。流程图、结构图和适合矢量表达的几何图优先提供 SVG / 矢量 PDF，并按实际生成方式附源文件或代码，PNG 用于方便预览。

不能将位图放进 SVG / PDF 就称为矢量图；确实需要栅格化的复杂曲面或像素数据按清晰度和文件体积选择合适格式。输出前确认白色背景、字体、线宽和标记在论文缩放后仍清楚。

用户要图片时交付图片；只要求代码时按需交付代码。不要默认把单独的图片请求做成 PPT 演示文稿。

## 交付与验证

1. 简短说明所用软件、输入数据、输出文件和建议图题。结果图附完整代码，示意图按选定方案提供矢量文件、源文件或生成代码。
2. 当前环境能运行对应工具时，实际执行并查看图片，检查坐标、单位、比例、图例、中文字体和留白；流程图检查连接逻辑，三维示意图检查空间关系与遮挡。
3. 当前环境没有 MATLAB 或其他指定软件时，如实说明哪些文件尚未经过该软件实机验证，不把替代工具生成的预览说成原软件运行结果。
4. 交付前删去与当前图无关的装饰、封装和注释，但不得删去单位、误差说明或影响解释的标注。
